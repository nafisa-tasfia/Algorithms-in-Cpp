# Algorithms in C++

This repository contains C++ implementations of algorithms practiced as part of my Computer Science and Engineering (CSE) coursework.

## Objectives

1. Practice implementing algorithms in C++.
2. Strengthen understanding of algorithmic concepts.
3. Develop programming and problem-solving skills through coursework.

## Language
 C++

## Repository Structure

Each `.cpp` file contains an individual algorithm implementation.

## How to Run

1. Open a `.cpp` file in Code::Blocks or another C++ IDE.
2. Compile the source code.
3. Run the program and provide input as required.
